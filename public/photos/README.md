# Your photos go here

## Today's banner (changes with the seasons)

Put photos in the folder for the season. Any number, any file names; Today shows a different one each day:

| Folder                    | Shows                 |
| ------------------------- | --------------------- |
| `public/photos/autumn/`   | September – November  |
| `public/photos/winter/`   | December – February   |
| `public/photos/spring/`   | March – May           |
| `public/photos/summer/`   | June – August         |

If a season's folder is empty, `public/photos/hero.jpg` is used. Landscape photos work best (the banner is wide
and short). Use `.jpg` or `.png` (not `.heic`), under ~1 MB each so the app stays quick.

## Avatar

`public/photos/profile.jpg`: the small round photo next to the greeting (square).

Photos for individual days are different: add those from inside the app (Calendar → camera on today).
