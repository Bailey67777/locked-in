# Submit-day videos go here

When you press **Submit day**, the app works out your percentage (habits + to-dos) and plays one of these.
Upload them on GitHub into `public/media/` with exactly these names (lower case):

| Your day                                         | File                 |
| ------------------------------------------------ | -------------------- |
| 80–100%                                          | `day-80-100.mp4`     |
| 50–79%                                           | `day-50-80.mp4`      |
| 25–49% (optional; falls back to the 0–25 video)  | `day-25-50.mp4`      |
| 0–24%, **or a ⭐ must-do habit was missed**       | `day-0-25.mp4`       |

- Any length is fine. `.mov`, `.m4v` and `.webm` also work with the same base name.
- GitHub's website only accepts files up to **25 MB**. Trim or compress longer videos first
  (on iPhone: record at 720p, or use a free compressor app).
- Until a file exists, the app shows the tier and tells you which file is missing.
